Coin Arena

Coin Arena — учебный Unity-проект для занятий по программированию и профориентации школьников.

Проект построен так, чтобы ученики могли изучать основы C# и Unity на практике, не погружаясь сразу в сложную техническую часть движка.

Вместо прямой работы с Rigidbody2D, Raycast, Collider2D, сохранениями и другими системами ученики используют подготовленные команды, например:

Controller.MoveLeft();
Controller.MoveRight();
Controller.Jump();
Controller.Dash();

Это позволяет постепенно изучать:

переменные и типы данных;
Start() и Update();
условия if / else;
методы и их аргументы;
bool, GameObject, null;
обработку клавиатуры;
взаимодействие между игровыми объектами.

В проекте уже подготовлены основные игровые системы: движение, прыжок, Dash, толчки игроков, монеты, счёт, возрождение, таймер, камера и визуальные элементы персонажей.

Главная цель проекта — дать ученику возможность быстро увидеть результат своего кода в настоящей игре, а затем постепенно переходить к более глубокому изучению Unity и C#.

Для кого

Проект рассчитан в первую очередь на:

школьников без опыта программирования;
профориентационные занятия;
вводные курсы по Unity и C#;
практические занятия по разработке игр.
